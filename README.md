# Builder Website — Draft

Responsive static website for a New Zealand building company.

## Preview
Open `index.html` in a browser. Internet access is required for the demonstration stock photographs and Google Fonts.

## IMPORTANT before publishing
- Replace **YOUR BUILDING COMPANY** with the verified business name.
- Replace all Unsplash demonstration photographs with photographs of the builder's actual projects, with permission. Do not represent stock images as completed projects.
- Confirm services, service area, experience, qualifications, and contact details.
- Configure a real form backend (e.g. Cloudflare Pages Functions, Formspree or equivalent) with spam protection and a privacy notice. The current form is a demo mailto action with no recipient.
- Verify any licensing, Master Builders/NZCB membership or guarantees before adding logos or claims.
- Add favicon, proper SEO title, local SEO metadata and privacy policy after confirming business information.

## Hosting
Deploy the folder as a static site on Cloudflare Pages or any static hosting service. No build command required.
